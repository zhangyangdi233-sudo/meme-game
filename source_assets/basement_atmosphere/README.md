# 地下室场景补丁（2026-10-10）

这是现有 `Basement_Loop_v2.glb` 的可编辑 Godot 场景补丁。原 Blender 工程和模型保留，进入地下室时由 `scripts/world/basement_atmosphere.gd` 重新布置当前实例。

- 场景单位为米。楼梯井右边界从 -1.69 调整到 -1.48，天花板、相邻墙面和碰撞一起调整。
- 桌面为约 0.88 × 1.56 米，高 0.79 米；两把原有木椅靠桌摆放，小椅子隐藏。箱子使用原模型，新增五个静止落稳姿态，不靠运行中物理抖动堆叠。
- 灯具缩到 73%，实际光源成为灯泡子节点并位于灯泡内；灯泡不遮挡自身发出的光。灯开关同时控制光源和灯泡自发光，CRT 单独供电。
- 新增钟、书、杯子、花瓶均由低面数基本网格构成；不使用外来模型。钟面用引擎字体，X-ray 数字为手画折线网格。
- 墙纸和地毯各有 256 × 256 的底色、法线、粗糙度图，另有透明裂痕/水渍贴片。纹理使用按米统一的三平面投射，避免大小不同的墙块把图案拉伸。

`tools/generate_basement_atmosphere.gd` 可重新生成上述原创贴图到 `assets/chapter1/atmosphere/`；导入编辑器后即可正常打包。后续可直接调整生成脚本中的颜色、纹理强度，或替换同名 PNG。

## 当前异常表

| 第几回 | 变化 | 玩家处理 |
|---|---|---|
| 1 | 正常灯光和一只挂钟 | 熟悉房间和墙上开关 |
| 2 | 入口封门 2.5 秒后闪灯，持续 3.6 秒 | 自动恢复；操作开关可提前接管 |
| 3 | 入口封门 3 秒后灯熄灭 | 找到楼梯脚旁墙上的开关按 F，恢复照明 |
| 4 | CRT 后面出现 18 只钟，各自指向不同时间 | 可放入后续彩蛋 |
| 5 | 挂钟缺少右半边 | 开启现有摄像头手势 X-ray 才能看到墙上的手写 1–5 |

每回出口桌从花瓶、书中选一个。选择使用存档里的 `decoration_seed`，重新开局可以不同，同一回读档保持一致。异常编号、持续时间、钟的位置集中在脚本顶部常量和对应函数中。

## 验证入口

- `tests/test_basement_atmosphere.gd`：实际导入模型、灯具父子关系、开关、五回异常、X-ray 图层、NPC 脚底和材质。
- `tests/test_reality_world.gd`：后续楼层 NPC 也只水平转向，面部遮挡层保持对齐。
- `tools/capture_basement_atmosphere.gd`：真实渲染截图；可加 `-- --visit=3` 查看第四回，`-- --visit=4 --xray` 查看第五回隐藏数字。
- 截图在 `docs/handoff/2026-10-10/evidence/atmosphere/`。单独的 `--xray` 截图只验证渲染图层；实际游戏继续使用原有手势窗口裁切，不会整屏显示隐藏数字。
