# 第二层住宅隐道、地图入场与纸条

2026-10-19，按当晚截图反馈实现。此前确认的 A 原实录厚毛毯脚步与 CRT 聚焦修复继续保留。

## 可直接检查的结果

- 第二层不生成任何 NPC。标题结束后固定玩家位置与镜头，手机自动滑出；地图图标保留灰态，再缓动变亮，完成时解锁并自动保存。结束后恢复 WASD，手机留在主页。标题期间也不能提前点击手机柄打断顺序。
- 设置和失焦暂停解锁；返回菜单取消。中途存档继续后，从收起手机和标题重新开始，不能提前获得地图。旧档已完成原 NPC 授权的记录迁移为已完成，不重复演出。
- 两处隐道改为完整住宅，与邻屋共用门窗、石基、屋檐和屋顶。普通视野看起来相同，X-ray 中露出真实道路；通路始终无碰撞，不切换玩家碰撞层、不传送。真实迷宫拓扑不变，旧战争迷雾记录保留。
- 原寻路人位置有受场景光照的纸片。F 打开后显示红色手写“墙不再是墙，路不再是路”；F、Enter、Esc 或按钮关闭，随后纸片消失并保存。日文/英文只附加译文，不替换中文原件。F10 设置暂时隐藏纸条，返回后继续阅读，不误记已读。
- CRT 教学提示按阶段移到暗区，避免遮住帖子、字块和发布按钮。规则投稿先放大确认，再进入暖红色规则卡；当前规则置前，替代后的历史规则使用灰色区分。真实规则和原投稿分别保留。
- 黄色路口的小墙保留，顶部横杆、灯条/灯光和假黑门取消；真正白光出口与物理路线保留。

## 研究与实现选择

比较 Godot 原生 Tween / 输入门控、Godot State Charts、GDQuest Tours、门户及 X-ray shader、3D 原位查看与独立阅读 UI 后，选择与现有工程直接相容的方案：小型可暂停控制器负责授权，视觉层与碰撞分离，纸条使用 Area3D 与阅读 Control。未引入整套编辑器或库存插件。
