## 2. 可直接用于 Aphasia 的总原则

**一句怪话应有正在完成的事情。** Milk 中的主角先要睡觉，又必须先找回散落的想法；她给房间设置不能移动物件的限制，随后主动提出点击式寻找。奇异语言同时解释目标、动作和限制，而不是只负责营造气氛。ZATO 的已读样本则常让一段对话改写人物关系，再令环境细节承担剩下的含义。

对 Aphasia 而言，任务对白可稳定落在：眼前看得见的不便 → 当事人为什么不能自己处理 → 玩家可以改写哪一条局部规则 → 场景发生可见变化 → NPC 的态度改变。主角的个性放在反驳、挑词、讨价还价和行动后的自我解释里；UI 把目标说清楚，人物不必每句都说清楚自己。

### 女主语言个性：可复用的机制

1. **她有偏好，也会不耐烦。** 嫌别人比喻不好、嫌建议无聊、想让别人配合自己的方法。`script.rpy:1148`（`choice1_ccc641a6`）对虫子意象的挑选、`pnc_text.rpy:2130–2148`（`bulbs_30c3bd25` 等）对搜灯建议的挑剔，都让她参与判断。
2. **她经常纠正措辞，以此重新分配责任。** 素描本对话 `pnc_text.rpy:1435–1492`（`notebook_2fdb1c40` 至 `notebook_ff6dd08d`）从出门买纸的困难，转到对对方句子和要求的不满。不要照搬具体侮辱；可保留“我不是拒绝，我只是指出你的要求有问题”的逻辑。
3. **她的逻辑会走偏，但中间步骤看得见。** 电风扇→翅膀→电线和罩子限制飞行→被关住的东西，见 `pnc_text.rpy:857–886`（`fan_ac72e700` 至 `fan_f0cb13c4`）。避免毫无过渡地把三个抽象词放在一起。
4. **她会得意、戏弄、突然认真，再绕开难题。** 网络朋友段落 `pnc_text.rpy:984–1247` 包括失败的类比、精确人数、自我纠正；这些明晰细节和迂回并存。Aphasia 主角可以证明自己算得对、记得清，但不必为所有人提供成熟的情绪解释。
5. **“不在乎”可成为表演，不只是信息。** `pnc_text.rpy:2222–2299`（`shkaf_be2fa242` 至 `shkaf_d2c4cf06`）越解释无所谓，越暴露在意；对话中的对方会打断，故有喜剧节拍。
6. **长独白与短回嘴分工不同。** 感官和联想多由旁白承载；人物面对对方时大量使用短答、质问、改口。让主角在长段解释之后有一个可以实际回应的短句。
7. **重复须有变化或压迫。** `zerk.rpy:7–379` 多次重复同一早晨语句，385–403 才改变开端；`lest.rpy:61–139` 把外来话语逐渐挤入主体语言。两个样本功能不同，不能把每个人都写成复读谜语。

不能把她的语言等同于特定临床诊断，也不能把其用药、依赖或攻击性对话当作现实治疗建议。这里只研究虚构角色的表达组织。

## 4. ZATO：长篇如何保持推进

从基础 AST 可确认主干按 `start → ep1 → ep2d1 → ep2d2 → ep2d3 → ep2d4 → ep2d5 → ep2d6 → ep2d7 → ep3` 顺序跳转；主要剧情文件没有 Menu 节点。它不能直接作为分支任务系统范本，但可以研究场景之间怎样传递问题。

| 已读位置 | 观察 | 对 Aphasia 的作用 |
|---|---|---|
| `tl/Chinese/script.rpy:7–520`，`start_2b370c74` 等 | 从太阳具体知识滑向观察、世界与被看见的自我论证；大量 extend 把一个意思分拍展开 | 主角世界观需要推理路径和可辨认的意象来源，不能一开始就堆结论 |
| `ep1.rpy:7–258`，`ep1_6b97733b` 至 `ep1_aa56e8a6` | 椅子、笔记本、动作与不同人物的反应先让事件成立，解释后置 | NPC 第一轮要给玩家看到某人正在干什么，以及哪里卡住了 |
| `ep1.rpy:266–594`，`ep1_16bce5ae` 至 `ep1_3958661a` | 从学校冲突扩到封闭小镇规则，再回到叙述者替别人辩解、归咎自己的心理 | 世界规则要通过人物受的具体影响进入，避免独立百科段 |
| `ep1.rpy:16200–16550`，`ep1_09efca5b` 等 | 强硬人物在脆弱时仍沿用赶人、挖苦的说话习惯；语气与身体状态相撞 | 同一个 NPC 可跨层变困境和情绪，但保留能辨认的表达动作 |
| `ep2d1.rpy:7–360`，`ep2d1_aef4bb1b` 等 | 热食、价钱和点单小争执建立相处感，再进入失踪者的时间线 | 两句日常小摩擦可以让 NPC 成为人，随后尽快引出眼前任务 |
| `ep2d1.rpy:4182–4278`，`ep2d1_01b52f6b` 等 | 离开后重新注意座位遮挡，由一件空间小事重读刚才的人际关系 | 后续对话不必再发奖励，可让 NPC 或环境细节重估刚完成的事 |
| `ep2d4.rpy:3718–4230`，`ep2d4_86189682` 等 | 重复记脸、换书、读童话、解释童话，显出叙述者维持某种世界观的劳动 | 主角的“证明正常”应有失败、补救和找理由的过程 |
| `ep2d7.rpy:6978–7501`，`ep2d7_886f29b4` 等 | 抽象数值规则通过双方的知识差、误会和价值冲突讲述 | 规则揭露也可以是一场争执，而不是讲师授课 |
| `ep3.rpy:13027–13461`，`ep3_f64fa101` 等 | 冷硬报告后切入解码者拌嘴，再把信号压缩成简短情感表达 | 大段设定的结尾宜落到可理解的人的需要；本次未读全终章，不外推全部结局含义 |

ZATO 的一条可移植节奏是：小事件 → 当事人各自说法 → 叙述者解释 → 一个细节令解释不再稳固。对 Aphasia，可把第三步缩短，把第四步交给规则操作后的画面与污染后的措辞。

## 5. 原创边界与对白验收

- 借用“具体物件引出语言偏移”“重复时改变信息”“争夺谈话主动权”等结构；不用牛奶、萤火虫、相同家庭情节、相同分支代价或特征性原句组成新人物。
- 不把 Milk 的“诶嘿嘿”、大量否定和断句当成完整角色。为 Aphasia 主角安排自己的偏好：不愿被看成帮不上忙、会挑对方措辞、把善意说成维护秩序、出错后坚持自己只是试一种可能。
- 不把 ZATO 的世界数值体系直接换几个名词放进 Aphasia。当前词句改写系统应通过门、站钟、点名、成绩、旧记录等本项目的对象证明其规则。
- 每个 NPC 至少能回答四件事：现在要完成什么；失败了谁具体受影响；为什么必须玩家改变规则；做成之后什么看得见地变了。
- 相同角色跨层复现应在“自己过不去 → 别人的声音也被忽略 → 谁拥有离开的权利”一类可验证的问题上递进，不能只让措辞更抽象。
- 污染后的句子须继续表达同一实际意思，但不用本次已经污染的普通词；UI 的目标、提示与插槽说明保持稳定。它是可玩性边界，不应拿来为玩家制造不可读的任务说明。
- 隐藏物角色完成帮助并谈完即可解锁；不将人格评判或某个唯一“善良答案”设为永久门槛。
