# 60% 污染闪回分镜(v2,已实现)

> 实现:`scripts/ui/pollution_flashback_director.gd` · 测试:`tests/test_flashback_sequence.gd`
> 音轨:`assets/generated/audio/pollution_flashback.wav`(3.70s,`tools/generate_audio_assets.py` 确定性合成)
> 研究依据:`docs/research/flashback_deep_research.md`

## 戏剧目的

这不是"主角发疯"的展示。它是第二层语言秩序失效的第一个不可逆证据:玩家听见同一句关怀先后被玩偶和医生占用,却无法确认哪一次是记忆、预演或修改后的历史。

设计范式:

- **Mouthwashing 公式**:冻结当下 → 声音先死 → 硬切。闪回"夺走当下",而不是"砸入画面",天然不构成 jump scare;
- **今敏式同构匹配剪辑**(Perfect Blue):关键句恒定钉在屏幕上,背后的世界(玩偶↔医生)整体替换——不是台词变化,而是归属变化;
- **污染只发生在元数据**:名牌文字、名牌边框(圆角↔直角)、引号体系(「」↔『』)可以变,正文字形一个都不变。

全长 3.55 秒(音轨 3.70s 含尾)。整局只触发一次。触发时剩余行动归零,结束后直接日结,不叠加常规三秒日过场。

## 实现要点

- 数据驱动:相位表是 `const PHASES`,时间线只由 `tween_interval` 串联,**零随机调用**(测试用源码扫描断言);
- 冻结帧:`viewport.get_texture().get_image()` 截帧,headless/取帧失败时退化为墨色底(测试环境安全);
- 关键句在两场中是两个同配置 Label,文本、字号、锚点完全一致;场景道具容器整体错位,句子不动;
- 名牌是唯一允许的差异:文字、边框形状(圆角/直角)、引号体系;
- 结束信号 `sequence_finished` → `_finish_pollution_flashback()`;直接调用 finish 可随时安全打断(测试覆盖)。

## 声音实现

- 全部由 `build_flashback_samples()` 确定性合成:房间底噪、布料噪声、电话带宽语音占位、单次门扣与反向尾音、9.7kHz 耳鸣细线、保存点击、编排静默;
- 不使用尖叫、突然爆音、心跳或随机倒放人声;最响的事件是静默本身;
- 播放电平 -8dB,低于 UI 点击声;闪回开始前底噪用 0.38s 先死(`_duck_ambience_for_flashback`)。

## 真结局回收

隐藏第四层再次出现相同空椅与缺边方框。空白说话者第三次说:

`我只是想让你留在安全的地方。`

此时不揭示"真正说话者"。回收的答案是:句子已经变成一条能自行寻找说话者的语言规则,而不是玩偶或医生的私有记忆。`区域：未记录` 卡片是第四层转场卡的预记忆。

## 可访问性(测试断言)

- 任意 1 秒滚动窗口内,明暗类别切换 ≤3 次(WCAG 2.2 [三次闪烁阈值](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html));相位表带 `luminance` 字段,由 `tests/test_flashback_sequence.gd` 独立重算校验;
- 每个相位 ≥120ms,两段黑帧 ≥150ms:黑帧是阅读标点,不是频闪;
- 动画不可跳过是因为它承担日结边界,但总时长 3.55s;结束后退出游戏立即可用。
