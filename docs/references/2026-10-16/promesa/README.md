## 本次第二层采用的视觉证据

- **06：夜色坡地街巷。** 深蓝黑天空占上方留白，近处两侧单层灰白建筑遮住通向远处的路线；中远处较高的多层建筑和台阶建立纵深。大多数窗洞是暗的，墙、地面有低分辨率颗粒，屋檐有清晰厚度。第二层保留自身原有丘陵地面，使用原创住宅和路线，不照搬图中的推车、盆、晾衣物。
- **01：狭窄连续巷道。** 两侧大面素墙、连续立面、少量门窗凹槽、跨巷楼体压缩视线；门洞与墙厚比装饰数量更决定空间的可信度。参考其建筑遮挡与窄巷节奏，第二层维持夜色。
- **09：围合院落。** 多层住宅包围低层附属建筑，楼高、立面分格与开口呈规律；近处留出空地，路线在墙角后隐藏。第二层可使用较短的院落作为迷宫中的停顿。
- **02：黑夜街道。** 高楼尺度、道路消失于远处、局部照明池与暗处形成层次。本次依用户要求不照搬汽车、树、路灯杂物。
- 00、03、04、05、07、08 展示了游戏其他差异很大的空间；它们不能作为“Promesa 全部空间都是蓝黑夜色”的证据。本次明确选择 06 为主、01/09 的空间语法为辅。

## 转译为本项目的实现约束

建筑使用规律网格与高低楼层序列，原有地形起伏保留；近景低房、中景转角、远景较高楼体。灰白墙通过低饱和材质与蓝夜光照得到色差，避免整栋自发光纯白方块。窗洞、门洞、窗台与屋檐必须有深度；小面积暖窗光仅作少量定位线索。表面可用原创程序像素纹理；参考图本身不进入游戏画面。移除第二层散落家具、标牌、漂浮图、独立遮挡屏和孤立灯具，让住宅本身形成迷宫边界与视线遮挡。

规则排布不等于空旷广场：主体路线在房屋间折返，围合外圈建筑背墙避免外围抄近路。NPC、必经转角、地图与出口共同使用同一个稳定布局数据，避免视觉街道和可通行判定不一致。
