## 先记住这条流程

全黑 2 秒 → 白门出现，走约 8–9 秒接近 → 听完敲门、按 F → 地下室五轮 → 十字路口 → 远门 → 第二层。

每轮在 CRT 拾字、组句、投稿，再向当轮 NPC 交付，随后按 F 从普通门离开。门慢开时镜头一起推进，前四轮连向下一地下室，第五轮连向十字路口。第 1、3 轮分别解锁手机的信号瀑布、笔记本；五轮都必须完成。

资金、每日行动限制、巴别塔 App、左侧资源栏、自动播放与历史入口已取消。污染只在后台运行，继续影响语言和后续剧情。

## 修改对照

| 用户反馈 | 本版处理 |
| --- | --- |
| 拾取字大小不同、拖字回原位、滚动慢 | 跟正文同字号；按落点恢复重力，宽 CRT 画布重绘也保留坐标；滚轮加快 |
| 天花板穿模、NPC 漂浮 | 调整楼梯顶开口与碰撞；NPC 只水平朝向玩家，按图像真实脚底落地 |
| 换语言漏译、鼠标被困住 | 补齐设置和 CRT 翻译；失焦释放鼠标，回到游戏后点击才重新捕获 |
| 灯与光源分离、CRT 光不够 | 灯具缩小，光源跟随灯泡且灯泡发光；微绿暗光，CRT 局部绿光加强 |
| 白门太亮、镜头不前进、循环出口空地 | 开场先黑屏并拉远、白光减弱；慢开门同步推进；循环用普通门，无旧隧道、白闪与出口小空地 |
| CRT 交互太远、镜头生硬 | 范围缩小；进入 0.8 秒、退出 0.65 秒缓动并恢复原视角 |
| 桌椅比例、杂物、墙与地毯 | 桌子放大靠楼梯，两椅拉开；小凳隐藏；增加箱堆、纸张、书杯等；磨损贴图、局部痕迹、法线和地毯织物 |
| 脚步与背景音 | 四种 CC0 地毯实录片段，按实际移动距离触发；背景音乐降低 5 dB |
| 下一层的大字动画 | 保留世界画面，2.6 秒无衬线到达标题，按真实楼层变化触发 |

## 异常与彩蛋入口

| 地下室轮次 | 变化 | 调整入口 |
| --- | --- | --- |
| 1 | 正常照明、单个墙钟 | 建立基准 |
| 2 | 入屋后闪灯约 3.6 秒，自动恢复 | `FLICKER_VISIT` |
| 3 | 入屋后断电，玩家到墙边按 F 开灯 | `BLACKOUT_VISIT` |
| 4 | CRT 附近 18 个钟 | `CLOCK_WALL_VISIT` |
| 5 | 半边钟，缺失的手写 1–5 只在手势 X-ray 中可见 | `BROKEN_CLOCK_VISIT` |
| 每轮 | 出口小桌随机放花瓶或书；同存档保持一致 | `decoration_seed` |

轮次常量使用从 0 开始的索引，集中在 `scripts/world/basement_atmosphere.gd`。手动开关会取消本轮尚未触发的灯光异常。三个原 X-ray 出口箭头仍保留。正常相机不会看到 X-ray 层。

## 接手与验收

原 Blender/GLB 保留在 `source_assets/blender_basement_loop_v2` 和 `assets/chapter1`；本轮房间修补、家具陈设与异常由运行时代码生成，不代表源 `.blend` 已同步重做。原创材质生成入口见 `source_assets/basement_atmosphere/README.md`，脚步来源及剪辑记录见 `assets/audio/foley/LICENSE.md`。

测试命令：`python tools/verify_basement_revision.py --godot <Godot可执行文件>`。自动使用隔离存档，完整日志写入本机 `artifacts/revision-final`。本次实际结果以 [verification.json](verification.json) 为准；旧每日预算、三 App 和黑隧道测试约定已随需求更新。

[环境证据](evidence/atmosphere)、[UI 证据](evidence/ui) 和 [门镜头证据](evidence/doors) 来自真实 OpenGL 渲染。真实摄像头、用户自备视频、Windows 系统键和耳机混音仍需人工实机体验；有些测试退出时报告既有富文本插件的固定资源清理诊断，记录中明确保留，不作为已修复项。
