# CRT 顶光、首次交互崩溃与地毯声音修订

本轮按用户截图与实际反馈直接修订。基线提交 `848710c`，继续使用 Godot 4.6.3 和 1016 分支；不改正式存档，不更换引擎，不删除文件。

## 证据与方向

1. 用户默认启动采用 Forward+/Vulkan。最新日志先出现 light/geometry unpair 错误，再 signal 11；已在原生 Vulkan 复现。问题发生于旁白结束时改变 CRT mesh 可见层并释放临时灯，按 F 才使坏引用暴露。官方 issue 121989 / PR 122064 与此匹配。
2. 顶光采用透明锥壳，只有纵向透明渐变，轮廓仍是实体锥边；目标为白门式柔光，不是让电视或字幕失焦。
3. 旧地毯采样用最高能量选段，含低频碰撞和次击；0.48 秒尾音长于快步间隔，单播放器重启时截尾。

## 实施顺序

- [x] 崩溃：`chapter_crt_focus_controller.gd` 改用入树前固定教学层的 CRT 镜像，不变更原模型层。镜像共享资源、原始姿态；结束与取消即恢复相机/灯光并释放临时对象。原生渲染覆盖完整七句后 F、存档继续、取消及场景释放。
- [x] 顶光：比较真实体积雾、透明锥壳、柔边片后采用兼容两渲染器的柔边散射；独立 shader 表达横向羽化和纵向消隐，小幅亮部光晕，黑背景保留。把光束可见性和主体照明分别控制。实际截图核验，保留电视机壳细节。
- [x] 脚步：替换为原创短纤维摩擦/闷步素材，保存可复现制作脚本与来源说明；调整步幅保证尾音完整，保留地面/暂停/传送等门控。检测样本次击、频带与步行/跑步调度，提供连续试听。
- [x] 整合：运行实际 Vulkan 与 Compatibility 渲染回归、CRT 真实输入教学、focus 恢复和音频专项。同步研究/验证文档。

## 验收边界

不以 headless 通过代替渲染崩溃验证；不以延迟释放、强制切 Compatibility 或永久保留灯光掩盖故障。声音客观检查不能替代用户设备上的主观试听。研究来源只作参考，不把受版权保护的电影截图或全文放入游戏资产。
