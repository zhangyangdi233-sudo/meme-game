## 已确定的体验

1. 开场为黑水与白门，起点距门 18 米。只有旁白流程完成事件能解除门闩；等待、靠近、穿越触发区都不能替代完成事件。
2. 进门抵达地下室楼梯顶入口。越过入口后，身后门关闭并锁定，无法返回开场。
3. 房间为长方形，楼梯贴左侧。下楼绕前方 TV 区，经右侧通道到后方 NPC 区。NPC 区前有隔墙，右侧留通道；左后方地面出口独立于楼梯顶入口。
4. 每轮只有一个可交互 NPC，完成其帮助事件才可使用出口。前四次出口重置到下一轮楼梯顶，第五次通向已有空旷十字路口。
5. 十字路口远门核验此前 NPC 给的三个物品，再通往下一层。三个物品的正式映射尚无可核实的配置，必须与旧隐藏结局物品分开。
6. TV 或 90 年代 CRT 是独立可替换模型。预留本地视频资源输入，默认空白屏幕，不下载或自动播放外部视频。

### 需要处理的运行时假设

- 玩家碰撞胶囊半径 0.34 米、高 1.72 米，胶囊中心相对脚底约 0.88 米。资产通道与门洞须按该体积验证。旧预览使用 0.25 米半径，不能以它的通过结果代替主工程验证。
- `_should_recover_reality_player` 使用全局 `y < -3`；`_recover_reality_player` 又强制 `y = 0.08`。地下室和楼梯需使用场景合同提供的可行走区域与安全点，不能沿用固定高度。
- `_refresh_nearby_reality_actor` 把高度差清零，且比较局部坐标。楼梯上下与带偏移的模型须按世界坐标、垂直距离及遮挡过滤，以免隔墙或隔层交互。
- `get_interactable_actors` 当前返回所有有效引用，不排除隐藏演员。地下室应只实例化本轮演员；空旷十字路口应明确关闭演员生成，不能仅隐藏外观。
- 序章的 `_advance_prologue` 仅隐藏文字覆盖层，没有持久化完成事件。`_skip_prologue` 不能成为正式门闩解锁入口。
- 输入回调会在序章遮罩可见时返回，但移动轮询没有同等条件。门闩须同时约束物理碰撞和场景转换，不能只挡键盘回调。
- 继续游戏当前一律跳过序章。新存档恢复应依据流程状态恢复门锁，避免加载绕过旁白。
- 日结算和污染边界能驱动旧楼层重建。开场和地下室阶段必须抑制这条空间转换路径；十字路口远门使用新路线的物品条件。

## 接口设计

### 流程状态

`JourneyProgress` 作为可序列化状态对象，由主游戏持有。`JourneyDirector` 消费世界事件并提出转换请求，世界宿主统一执行换场、位置恢复及一次性防重复处理。

保存内容：`schema_version`、`phase`、`round_index`（0 至 4）、`narrator_completed`、`entrance_locked`、`completed_task_ids`、`claimed_reward_ids`、`gate_item_ids`、`transition_serial`、`config_id`。阶段为 `opening`、`basement`、`crossroads`、`tower`；门的外观及是否可触发由状态推导，不另外保存会漂移的计数。

| 输入事件 | 必须检查 | 结果 |
| --- | --- | --- |
| `narration_completed(sequence_id)` | 当前开场及预期序列 ID | 门闩解除，允许进入白门；重复事件无副作用 |
| `opening_door_crossed` | 当前开场且旁白完成 | 进入第一轮楼梯顶 |
| `entrance_threshold_crossed` | 玩家已从外侧越过入口安全平面 | 关闭并锁住身后门；该轮不再打开 |
| `npc_help_completed(task_id, round_token)` | 当前轮任务匹配、帮助系统确认、轮次 token 有效 | 记录帮助完成，发放一次配置奖励，允许出口 |
| `basement_exit_requested(round_token)` | 当前轮已帮助完成、转换尚未消费 | 前四轮递增并重置楼梯顶；第五轮进入十字路口 |
| `crossroads_gate_requested` | 五轮全部完成，所需三个唯一道具 ID 齐全 | 开门并进入配置的下一层 |

旁白完成与靠近门是两个独立条件。帧时间、计时器和移动距离均不得触发 `narration_completed`。区域触发器只提出请求，所有条件由流程状态再次核验。

调试入口只在开发构建且显式启用参数时出现，并持续显示“开发验证”。它能发出旁白完成、当前 NPC 帮助完成及测试道具事件，使用与真实系统相同的校验入口，不直接修改轮数。正式启动默认不开放调试完成按钮或快捷键。

### 世界接口

世界宿主为当前阶段提供 `spawn_transform`、可行走范围、安全恢复点、当前演员与物品、门口触发器。旧十字路口由现有 generator 提供；新增模型由包装场景提供，不通过继承整个街区生成器实现地下室。

进入阶段时清零速度、恢复视角、设置该场景环境，并停用上一场景的碰撞和交互。转换以 `transition_serial` 防重入。前四次循环加载同一资源，重建运行时状态，不复制五份模型。

新流程进入十字路口时关闭其 NPC、玩偶与旧收藏物人口生成，保留道路、边界和既有建筑。旧路线和回归测试仍可按原配置生成完整人口。远门是独立包装节点，不替换十字路口地图。

### 资产合同要求

以下名称为建议逻辑键，必须在实际合同到达后映射到真实 GLB 节点，不要求建模端盲目采用这些命名：

| 逻辑键 | 含义 |
| --- | --- |
| `spawn_stairs_top` | 玩家脚底出生变换与朝向，入口外侧且胶囊有余量 |
| `entrance_threshold` | 越过后可安全关门的位置及正反方向 |
| `entrance_door` | 独立门叶或门叶根节点、铰链变换、门洞尺寸 |
| `npc_anchor` | NPC 落脚点与朝向；只有本轮角色被实例化 |
| `exit_door`、`exit_threshold` | 左后地面出口的独立门叶与转换平面 |
| `tv_anchor`、`screen_surface` | 独立 CRT 插槽和屏幕网格／材质槽 |
| `safe_floor`、`safe_stairs_top` | 按真实高度保存的安全落点 |
| `walkable_bounds` | 房间及楼梯有效范围，不能只用平面矩形代替楼梯高度 |

使用米为单位；记录 Blender 到 Godot 的坐标转换。Godot 竖直轴为 Y，摄像机默认前方为负 Z。出生点必须注明脚底还是眼睛；现有 opening manifest 的 `(0, 1.65, 0)` 是眼高，不能直接作为主工程玩家脚底位置。

静态碰撞使用明确代理网格或导入碰撞，楼梯优先有连续可行走斜坡代理。碰撞层与主工程层 1 对齐，门叶碰撞由门控制器单独开关。必需标记缺失时中止该路线并给开发诊断，不静默加载旧地下室。

开场来源为 `outputs/blender_subliminal/Opening_WhiteDoor.glb`，其 manifest 已确认 18 米距离、米制单位及无门叶碰撞。包装场景必须增加运行时阻挡，并在任何入口请求时再次核验旁白完成。

新版地下室预期路径为 `outputs/blender_basement_loop_v2`。`Basement_Architecture.glb` 是旧房型，不能成为新版默认或隐式回退。

### 视频接口

CRT 包装节点接收本地 `VideoStream` 资源并输出播放完成、失败、停止事件，屏幕通过专用材质绑定视频纹理。接口支持 `set_stream`、`play`、`stop`；默认不自动播放。无资源时黑屏，资源无效时记录开发错误，均不阻塞循环流程。模型替换只需满足 `screen_surface` 与插槽变换，不修改 NPC 或门锁代码。

### 存档兼容

当前外层文件版本为 1，`MemeGameState.SAVE_DATA_VERSION` 为 5；不要把旧的 save_v2 设计记录误当运行版本。新状态应嵌入命名空间，不污染旧收藏字段。旧存档缺少新字段时保留既有路线和位置，不强迫已有进度重播地下室。新游戏进入新路线。

恢复必须先选对世界阶段，再应用该阶段的玩家位置与门锁。在旁白未完成、楼梯半途、帮助前后、四次循环和十字路口分别保存恢复，不能靠隐藏旧序章遮罩代表旁白已经完成。

## 实施顺序

1. 阅读开源比较报告，核对新模型合同与 GLB 节点、材质槽、碰撞、米制尺寸和朝向。
2. 为流程状态添加有意义的行为测试，再实现事件门闩、轮次、幂等奖励和序列化。保留真实旁白与任务完成接口，开发配置明确标记。
3. 添加开场与地下室包装场景，连接现有移动控制器，处理坡道、世界坐标交互及安全恢复。
4. 连接五轮循环、空旷十字路口与独立远门条件，接回现有下一层入口；按合同接入 CRT 插槽。
5. 运行下面的验收矩阵，完成真实渲染捕获与自动行走，再给出运行方式。任何仅通过状态测试的结果不能称为已跑通游戏。

## 回归与验收

| 范围 | 必须验证 |
| --- | --- |
| 开场门闩 | 等待至少 30 秒、走到门前、强行越过触发区均不能换场；只有匹配的完成事件打开门；重复事件不重复换场 |
| 入口 | 顶端出生不与门或天花板重叠；进门后关锁；返身无法回开场；下一轮入口重新建立正确状态 |
| 楼梯与动线 | 主工程 0.34 米胶囊连续下楼、绕 TV、走右侧通道、抵达 NPC 和左后出口；没有跌落恢复误触发或隔墙互动 |
| NPC | 每轮恰好一个可交互 NPC；错误任务 ID、过期 token 和只结束聊天均不能放行；完成事件只发奖一次 |
| 五轮出口 | 未完成均锁定；第 1 至 4 轮恰好回楼梯顶；第 5 轮恰好进十字路口；连续触发不跨过两轮 |
